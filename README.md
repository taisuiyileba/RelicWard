# 遗境守望 · Relic Ward

**1.0.0 · 沉钟古庭**

Minecraft 1.20.1 的 Forge 冒险模组，围绕一座青铜古庭、一位两阶段 Boss 和可重复挑战的装备成长展开。

探索沉钟古庭，敲响启战钟，挑战执钟者·玄铎。跳过扩散钟波，诱导冲撞击碎谐振柱，在破甲失衡时反击；击败守卫后，打造钟铸装备、收服铜傀伙伴，再次开启挑战。

作者：**taisuiyileba** · 开源协议：[MIT](LICENSE)

## 环境与安装

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.10 或更高的 47.x 版本 |
| Java | 17 |
| 必需前置 | Curios，适用于 Minecraft 1.20.1 的 5.14.1–5.x 版本 |
| 可选兼容 | Jade 11.x，可查看玄铎的钟甲层数与减伤 |

1. 准备符合上述要求的 Forge 实例，并安装 Curios。
2. 将 `relicward-1.0.0.jar` 放入实例的 `mods` 文件夹，移除其他版本的 Relic Ward，避免重复加载。
3. 完全退出并重新启动游戏。多人游戏的客户端与服务器均需安装相同版本的模组和必需前置。

源码构建产物位于 `build/libs/relicward-1.0.0.jar`，构建方法见下方“从源码构建”。本模组不依赖灾变或 GeckoLib。

## 探索与开战

沉钟古庭可在森林、针叶林、平原、草甸和热带草原等群系自然生成，包含山门、回廊、侧院、探索宝箱、主庭和断钟塔。旧存档需要探索尚未生成的区块，已有区域不会自动补建古庭。

拥有指令权限时，可定位最近的古庭：

```mcfunction
/locate structure relicward:resonant_court
```

进入主庭，在**生存或冒险模式、非和平难度**下右键启战钟。创造模式可用于观察，不计入参战人数。

### 挑战玄铎

- **两阶段战斗**：包含横扫、重敲、钟波和冲撞；半血进入第二阶段，加入双扫、双波与铜傀援军。
- **三柱钟甲**：每根谐振柱提供 10% 减伤。诱导玄铎撞柱可破除对应钟甲，并使其失衡 5 秒；失衡期间关闭钟甲，受到的伤害提高。
- **钟波与裂甲**：看准波环接近的时机起跳。钟波命中会附加裂甲，暂时降低护甲与护甲韧性。重敲、冲撞和钟波不能用盾格挡。
- **二阶段超重力**：主庭内的生存玩家受到移动、跳跃和飞行限制，钟波仍可通过准确起跳躲避。离场或战斗结束后解除。
- **多人挑战**：支持 1–4 人生命缩放，并记录玩家及其铜傀伙伴的战斗贡献。
- **撤离重试**：没有封门屏障。全员离开主庭约 10 秒后，Boss 与谐振柱复位；存档重新加载后，未完成的战斗也会复位。

专属 Boss 血条显示阶段与护柱信息，战斗配乐随阶段切换。主要攻击预警使用几何与纹理，最低粒子设置下仍可看见。

### 战利品与再次挑战

正常击败玄铎后，材料以**共享实体掉落物**形式出现在地面：沉钟之核 ×1、铜律碎片 ×6–8、青铜纹砖 ×12–20，经验通过地面经验球发放。抢夺可增加碎片与纹砖数量，不增加核心。

古庭挑战中，合格参战玩家首次获得的**玄铎钟冠**会自动送入背包。背包已满时保留待领取记录，腾出空间后自动补发，无需右键钟领奖。钟冠是可放置的发光纪念摆件，不提供战斗属性。

胜利后等待 5 分钟，附近有玩家时玄铎会重鸣归位，再次敲钟即可挑战。也可在冷却期间**手持铜律碎片右键启战钟，消耗 5 块碎片立即重开**；仍需满足模式、难度与场地条件。探索宝箱不会随 Boss 挑战刷新，管理员清除 Boss 不产生正常战利品与奖杯。

## 装备与铜傀伙伴

| 装备 | 使用方式与效果 |
| --- | --- |
| 回响钟锤 | 主手长按右键，蓄力 0.9 秒后进入 0.5 秒落锤，命中前松开取消。普攻总伤害 11、攻速 1.1、耐久 960；震击前方 5 格 / 120°，基础伤害 14，附加 5 秒裂甲，冷却 5 秒 |
| 震律鸣钟 | 站在地面右键释放扩散钟波；耐久 384，每次消耗 2，冷却 8 秒，可用钟铸铜板修理 |
| 守律铜盾 | 右键即时起盾；举盾最初 0.5 秒内成功格挡可免除本次耐久损耗、清除自身裂甲，并反震近处攻击者；精准格挡冷却 4 秒 |
| 钟铸护甲 | 四件套提供 18 点护甲；每件提供 1 点护甲韧性与 5% 抗击退，可用钟铸铜板修理 |
| 守钟坠 | 装入 Curios 项链槽并持续佩戴 3 秒后生效；单次达到 6 点的生物来源最终战斗伤害减少 30%，冷却 25 秒 |
| 钟铸砧 | 支持修复、合并附魔和改名，采用原版经验费用，不会下落或损坏 |

钟锤震击不破坏方块，需要前方有地面且目标可见；同类技能的冷却不会因更换物品而重置。建筑与装饰内容还包括青铜纹砖、回纹铜砖、余响灯和垂铃灯。合成配方以游戏内配方及 [配方资源](src/main/resources/data/relicward/recipes) 为准。

使用**契律印**右键未契约的巡庭铜傀即可收服。伙伴跟随主人并协助战斗，空手右键切换跟随与待命；使用铜傀修补膏可恢复生命。伙伴死亡后不会自动复活，可重新收服新的铜傀。

每座古庭维持四个野生巡逻名额，死亡或被收服后按冷却补充，需区块加载且落点安全。Boss 二阶段召唤的援军不可契约，也不会掉落材料或经验。

## 配置与场地保护

### 自然生成距离

首次启动后，可在 `config/relicward-common.toml` 修改：

```toml
[worldgen]
courtDistanceBlocks = 2000
```

范围为 512–16000，数值越大，古庭越稀疏。它是生成距离的目标参数，实际分布受种子、地形和群系影响，不保证每隔指定距离出现一座。

退出游戏或服务器后修改，重启生效，仅影响尚未生成的区块。多人服务器以服务器端配置为准。

### 画面与音乐

`config/relicward-client.toml`：

```toml
impactCameraShake = true
customBossBar = true
bossMusic = true
bossMusicVolume = 0.65
```

以上选项分别控制重击镜头震动、专属 Boss 血条、战斗音乐和音乐音量倍率（0–1）。战斗音乐同时受游戏内“主音量”和“音乐”滑块控制。关闭专属血条后使用原版 Boss 条。

### 主庭保护

主战庭院、两侧回廊与后方钟塔受到保护，限制生存模式的挖掘、放置和常见环境破坏，创造模式保留维护能力。侧院探索区域不属于主庭保护区。结构布局更新不会自动覆盖已有古庭，查看新布局需要探索新区域。

## 测试与管理员指令

在测试世界的空地放置古庭：

```mcfunction
/relicward place_court
```

此指令会在执行位置北侧放置约 65×81 格的古庭，替换模板范围内的地形与建筑，朝向不随玩家视角改变；完成后输出启战钟坐标。

常用测试物品：

```mcfunction
/give @p relicward:bell_warden_spawn_egg
/give @p relicward:court_puppet_spawn_egg
/give @p relicward:echo_maul
/give @p relicward:resonant_bell
/give @p relicward:warden_pendant
```

静态观察玄铎模型：

```mcfunction
/summon relicward:bell_warden ~ ~ ~ {NoAI:1b,PersistenceRequired:1b}
```

## 从源码构建

准备 **JDK 17**，在仓库根目录使用随附的 Gradle Wrapper：

```powershell
# Windows
.\gradlew.bat build
```

```sh
# Linux / macOS
sh ./gradlew build
```

输出文件：`build/libs/relicward-1.0.0.jar`。首次构建需要联网下载 Gradle 与 Forge 依赖。构建使用 `libs/` 中随仓库保留的 Curios 与 Jade 依赖；Jade 对玩家运行模组而言是可选项。

日常构建无需重新生成美术资源。需要修改资源时，`tools/` 提供 Python 生成与验证脚本，通常需要 Python 3.10+ 和 Pillow。生成脚本会覆盖对应导出文件，请先保存手工修改；Blockbench 修改不会自动同步到 Java 模型。

开发验证命令：

```powershell
python tools/verify_assets.py
.\gradlew.bat runGameTestServer
.\gradlew.bat runClientSmoke
```

资源验证需先完成构建。游戏测试使用项目内的 `run-gametest/` 与 `run-client-smoke/` 目录；客户端自动测试需在其 `options.txt` 设置 `onboardAccessibility:false`。
